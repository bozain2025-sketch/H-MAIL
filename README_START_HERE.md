# MailHub — حزمة بناء تطبيق بريد إلكتروني للماك (Apple Silicon)

**التاريخ:** 12 أكتوبر 2026  
**الحالة:** خطة عمل + Skill تصميم جاهزة للاستخدام. **ليست تطبيقًا مبنيًا** ولا تحتوي على بيانات حسابات حقيقية.

## افتح الملفات بهذا الترتيب

1. **`MASTER_PLAN.md`**: الخطة الهندسية الكاملة باللغة العربية؛ مرجع التنفيذ الأساسي.
2. **`UI_DESIGN_SPEC.md`**: مواصفات تصميم الواجهة والمكونات والحالات.
3. **`prompts/START_AGENT_EN.md`**: رسالة جاهزة للصقها في نموذج البرمجة؛ تُلزمه بقراءة الخطة وتنفيذها تدريجيًا.
4. **`docs/ACCEPTANCE_CHECKLIST.md`**: اختبارات القبول وشروط اعتبار النسخة جاهزة.
5. **`docs/REFERENCE_LINKS.md`**: مصادر رسمية للأجزاء التي قد تتغير.
6. **`skills/macos-mail-ui/SKILL.md`**: مهارة مخصصة لتصميم واجهة بريد ممتازة على macOS. معها ملفات مرجعية وCSS وفحص لتباين الألوان.

## كيف تعطيها لموديل البرمجة؟

- فك الضغط داخل مجلد مشروع على **Mac بمعالج M1 أو أحدث**.
- افتح المجلد في محرر يدعم Coding Agent (Claude Code أو Codex CLI أو أي Agent آخر).
- اطلب من الموديل قراءة `prompts/START_AGENT_EN.md` و `MASTER_PLAN.md` و `UI_DESIGN_SPEC.md` أولًا، ثم البدء في المرحلة 0.
- لو الموديل يدعم مجلد Skills، انقل `skills/macos-mail-ui/` إلى مجلد المهارات في بيئة الموديل. مثال شائع لـ Claude Code داخل المشروع: `.claude/skills/macos-mail-ui/`. المسار يعتمد على أداة الموديل.
- لو لا يدعم Skills تلقائيًا، اطلب منه قراءة `skills/macos-mail-ui/SKILL.md` والملفات المرجعية المشار إليها قبل كتابة الواجهة.
- **التصاريح OAuth**: لا تُدخل أسرار Google/Microsoft داخل المحادثة أو ملفات المشروع. ستحتاج إعداد تطبيق OAuth خاص بك عندما تصل لربط الحسابات الحقيقية.

## حدود متعمدة

- افترضنا أن عدد الحسابات قد يصل إلى المئات وربما ألف بعد اختبارات التحمل. لا يعني هذا أن كل حساب سيتصل كل ثانية.
- بداية التنفيذ تركز على IMAP/SMTP وحسابات Google/Microsoft عبر مسارات OAuth الصحيحة، مع مراحل واضحة بدل ادعاء دعم جميع الخدمات في أول نسخة.
- نستهدف `aarch64-apple-darwin` وليس Universal؛ يمكن توسيع دعم Intel لاحقًا فقط إذا أردت ذلك.
- حجم البرنامج المتوقع سابقًا (20–60 MB) **تقدير غير مضمون**؛ يتحقق بقياس نسخة Release النهائية على Mac.

## المهارة المرفقة

`macos-mail-ui` مهارة أصلية مخصصة لهذه الحزمة، وليست نسخة تم تنزيلها من مستودع جهة خارجية. تضيف قواعد محددة لواجهات البريد وكثافة المحتوى والتعامل مع العربية والإنجليزية وعناصر macOS. توجد كذلك مهارة عامة مفتوحة المصدر للاطلاع الاختياري: [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)، لكنها **غير مضمّنة** هنا.

## اختصارات إضافية للموديلات

- `AGENTS.md`: تعليمات تلقائية مناسبة لعدد من Coding Agents بما فيها Codex.
- `CLAUDE.md`: مدخل مختصر لـClaude Code.
- `docs/PROVIDER_MATRIX.md`: جدول دقيق لفروق Gmail/Graph/IMAP.
- `install/skill.zip`: **نسخة مستقلة جاهزة من المهارة** إذا كان النموذج يدعم استيراد ZIP لمهارة واحدة. والمجلد المفكوك `skills/macos-mail-ui/` موجود كذلك للاستخدام المباشر.
